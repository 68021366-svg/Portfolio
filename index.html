ประวัติของฉัน

ชื่อ-นามสกุล: นายศุภวิชญ์ ตรีอินทอง

ชั้นปีและสาขาวิชา: นิสิตชั้นปีที่ 2 สาขาวิชาวิทยาการคอมพิวเตอร์

สวัสดีครับ เป้าหมายในการเรียนรายวิชานี้ของฉันคือการพัฒนาทักษะด้านการพัฒนาเว็บแอปพลิเคชัน ทั้งในส่วนของ front-end และ back-end เพื่อนำไปต่อยอดในการทำโปรเจกต์ของฉันและงานอื่นๆ ตลอดปีการศึกษานี้ครับ

ทักษะ

  • Front-end
    • HTML
    • CSS
    • JavaScript
  • Back-end
    • Java
    • Python
    • Node.js

เป้าหมายในภาคการศึกษานี้

  1. สามารถเขียน HTML พื้นฐานได้และเขียนได้อย่างถูกต้องตามหลักสากล
  2. สามารถเขียน CSS พื้นฐานและรู้วิธีการใช้ Framework ต่างๆ
  3. สามารถเขียน JavaScript พื้นฐานและรู้วิธีการใช้ Framework ต่างๆ
  4. รู้วิธีการสร้าง Web application ในทุกๆขั้นตอนแบบละเอียด และ สามารถเป็นสร้างเป็น software แล้ว Deploy ใช้งานได้จริง
